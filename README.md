# زرین | Zarrin Jewelry

قالب تک‌صفحه‌ای مستقل برای بوتیک جواهرات زرین، با فارسی راست‌چین، محتوای انگلیسی تزئینی، طراحی سینمایی تیره، کارت‌های سه‌بعدی، ذرات درخشان و چیدمان واکنش‌گرا.

## اجرا

فایل `index.html` را در مرورگر باز کنید؛ برای بهترین تجربه، از یک سرور محلی استاتیک استفاده کنید (مثلاً `python -m http.server 8000`) و سپس `http://localhost:8000` را باز کنید. این پروژه به build step یا وابستگی npm نیاز ندارد.

## محتوا و سفارشی‌سازی

- رنگ‌ها، تایپوگرافی و فاصله‌ها: `css/tokens.css`
- استایل پایه، ناوبری، قهرمان، بخش‌ها و موبایل: سایر فایل‌های `css/`
- تعاملات مستقل: فایل‌های `js/`
- تصاویر از Unsplash، آواتار نمونه از pravatar.cc و ویدیوی پس‌زمینه از Pexels بارگذاری می‌شوند؛ برای استفادهٔ production منابع و مجوزهایشان را بررسی و در صورت نیاز میزبانی محلی کنید.
- فرم تماس نمایشی است و پیام موفقیت را در مرورگر نشان می‌دهد؛ برای دریافت واقعی فرم را به سرویس backend متصل کنید.

## English

A standalone, dependency-free Persian/English luxury jewelry storefront template. Open `index.html` directly or serve this folder with any static web server. External images, Google Fonts, and the atmospheric hero video require an internet connection. The contact form is a front-end demo and needs a backend integration for real submissions.
